How to Play

1

Read the Question

You have 20 seconds to read and understand the MCQ question carefully.

📖
2

Click NEXT / START GAME

After reading, click the button to start the Snake game round.

⏱️
3

Control the Snake

Four answer options (A, B, C, D) are placed inside the game board at random positions.

🐍
4

Eat the Correct Option

Move the snake to eat/touch the option you believe is correct.

✨
5

Get Instant Result

Correct answer gives points! Snake grows bigger and faster for next question.

⭐
6

Complete All 20 Questions

Difficulty increases with each question. See your final score on the leaderboard!

🏆

Rules & Features

🎯 Total Questions

20 MCQ Questions total from Python and C programming

20 seconds to read and understand each question

30 seconds time limit in snake game

All four answer options (A, B, C, D) appear at random positions inside the game board

✅ Correct Answer

+100 points + Bonus points for reading time remaining

❌ Wrong Answer

0 points - No penalty, move to next question

📈 Progressive Difficulty

Snake size ↑ | Speed ↑ | after each correct answer
